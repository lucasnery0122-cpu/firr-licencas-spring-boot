# 🚀 FIIR - Gestão de Licenças com Spring Boot

Sistema para cadastro, consulta e gerenciamento de licenças, desenvolvido em **Java** com **Spring Boot**.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java
* **Framework:** Spring Boot (Spring Data JPA / Spring Web)
* **Banco de Dados:** PostgreSQL / H2 Database
* **Gerenciador de Dependências:** Maven

---

## 📌 Funcionalidades

* ➕ **Cadastro de Licenças:** Registro de novas licenças com dados essenciais.
* 🔍 **Consulta:** Listagem e busca de licenças cadastradas.
* 🛠️ **Gestão:** Controle de status e regras de negócio de licenciamento.

---

## 📂 Estrutura do Projeto

* `src/main/java`: Regras de negócio, controllers, repositories e entities.
* `src/main/resources`: Configurações de ambiente (`application.properties`).
